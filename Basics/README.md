# C++ Fundamentals

This directory contains my study records for the fundamental features of modern C++20.

The purpose of this stage is to build a reliable foundation before studying classes, the Standard Template Library, resource management, and simulation architecture.

## Learning Objectives

In this stage, I will learn how to:

* compile and run C++20 programs,
* declare and initialize variables,
* use operators and expressions,
* control program flow with conditions and loops,
* write and call functions,
* use basic standard-library types,
* understand references, pointers, and `const`,
* and separate a program into multiple source files.

## Study Structure

Each study topic is organized into a separate Day directory.

```text
dayXX_topic/
├── README.md
├── practice.cpp
└── main.cpp
```

### `practice.cpp`

Used for:

* examples typed while reading the book,
* syntax experiments,
* selected textbook exercises,
* testing different values,
* and checking unexpected behavior.

### `main.cpp`

Contains a small applied program built using the concepts studied that day.

The goal is to combine the learned syntax into a program with a clear purpose.

### Daily `README.md`

Records:

* topics studied,
* the program created,
* mistakes and corrections,
* observations about C++ behavior,
* and the next topic.

## Completion Criteria

The fundamentals stage will be considered complete when I can:

1. write and compile a small C++20 program without copying,
2. explain the purpose of each major statement,
3. modify the program and predict the result,
4. diagnose basic compiler errors,
5. use functions, containers, references, and `const`,
6. divide a small program into multiple files.
